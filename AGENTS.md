# Velocious Search AGENTS

- Source is JavaScript/JSX with `// @ts-check` and precise JSDoc contracts.
- `build/` is generated by `npm run build`; never edit or commit it.
- Keep frontend and backend entrypoints separate so browser imports never load Node/database modules.
- Use React Native-compatible primitives in components and stable `testID` selectors.
- Public modules are imported through explicit package subpaths; do not add a barrel export.
- Add focused tests before production behavior changes and run them with `npm test -- <spec-path>`.
- Before committing, run `npm run lint`, focused tests, `npm run build`, and `npm pack --dry-run`.
- Public API changes require README/docs updates and a timestamped `changelog.d/` fragment.
- Do not manually edit the package version during feature work. Releases use `npm run release:patch` after explicit approval.
- Never push directly to `master`; publish feature work through a pull request.
